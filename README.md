# Chemistry Experiment Project - Biodiesel Production

A professional, modern website for documenting and presenting a chemistry group project on biodiesel production using ultrasonic transesterification.

## 📋 Project Structure

### 7 Main Modules

1. **Home Page** - Group details with member information and faculty supervisor
2. **Chemicals & Materials** - Complete list of reactants, catalysts, solvents, and equipment
3. **Experimental Procedure** - Step-by-step timeline guide (7 phases)
4. **Process & Workflow Diagram** - Visual flowchart and reaction conditions
5. **Photo Gallery** - Space for laboratory photographs (add your images)
6. **Video Content** - Section for experimental videos (add your videos)
7. **FAQ & Q&A** - Common questions and answers about biodiesel

## 🎨 Features

- **Professional Design**: Modern gradient layouts with smooth animations
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Elements**: Expandable FAQ section, smooth scrolling, hover effects
- **Clean Code**: Well-organized HTML, CSS, and JavaScript
- **Accessibility**: Semantic HTML and proper contrast ratios
- **Fast Performance**: Optimized animations and lazy loading support

## 🚀 How to Use

### Adding Photos

1. Take photos of your lab work
2. Add image files to `assets/photos/` folder
3. Update gallery section in index.html to use actual image paths

### Adding Videos

1. Upload videos to `assets/videos/` or use YouTube links
2. Update videos section in index.html with video sources

### Customizing Member Information

Edit the table in the Home section to add your group members and faculty details.
